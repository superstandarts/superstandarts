# `> philosophy`

```txt
BUILD SOMETHING
KEEP IT CLEAN
MAKE IT FEEL DIFFERENT
```

I care a lot about how software **feels**, not only about whether it works.

The goal is usually to make something that is:

```txt
simple
fast
useful
visual
custom
memorable
```

A good interface should feel like a place you want to stay in.
